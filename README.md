# 网页 AI 答题助手

自动识别网页上的题目，调用你**自定义配置**的大模型 API（OpenAI 兼容接口，如 DeepSeek / OpenAI / Moonshot 等），生成并填入答案。界面为右下角小浮窗，不遮挡原页面。

提供两种形态，**二选一**即可：

| 形态 | 文件 | 是否需要管理器 |
|---|---|---|
| 🐒 用户脚本 | `web-ai-quiz-assistant.user.js` | 需要 Tampermonkey / Violentmonkey |
| 🧩 Chrome/Edge 扩展 | `ai-quiz-extension/`（或 `ai-quiz-extension.zip`） | 不需要，直接加载 |

---

## 功能特性

- **模型完全可配**：API 地址 / API Key / 模型名 / 温度 / 超时 / 自定义请求头 / 系统提示词
- **流式输出**（默认开），可切非流式；支持**批量模式**（一次请求全部题目）
- **识别题目**：常见平台选择器 → 启发式扫描，并覆盖**同源 iframe**；也支持**🎯 手动点选**（最可靠）
- **干净解析**：从题目文本按 `A. B. C. D.` 拆出题干 + 选项，自动去题号/分值/题型噪声，不再出现碎片重复
- **自动填入**：单选 / 多选 / 判断 / 填空 / 简答，字母或语义匹配选项并勾选；也可手动点选项后再填入
- **小浮窗**：右下角，可拖动、最小化、关闭；模型设置默认折叠（点「⚙ 模型设置」展开）
- **诊断按钮**：查看选择器命中数、iframe 数量、API 是否配置，便于排查

---

## 方式一：篡改猴（Tampermonkey）用户脚本

### 安装
1. 浏览器安装 **Tampermonkey**（或 Violentmonkey）。
2. 篡改猴 → 管理面板 → 添加新脚本 → 粘贴 `web-ai-quiz-assistant.user.js` 内容并保存；或直接导入该 `.user.js` 文件。

> ⚠️ 不要用 Greasemonkey 4+：它的 API 是 `GM.xmlhttpRequest` 命名空间，本脚本不兼容。

### 使用
1. 打开任意网页，右下角出现 **AI** 按钮，点击打开面板。
2. 点「⚙ 模型设置」→ 填 API 地址、API Key、模型名 → 点「测试连接」→「保存配置」。
3. 点「🔍 识别题目」→ 自动识别并逐题请求，答案显示在列表中，可「填入答案」或「复制」。

---

## 方式二：Chrome / Edge 扩展（无需篡改猴）

### 安装
1. 解压 `ai-quiz-extension.zip`，得到 `ai-quiz-extension` 文件夹。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开右上角「**开发者模式**」。
3. 点「**加载已解压的扩展程序**」→ 选中 `ai-quiz-extension` 文件夹。

### 使用
与方式一相同：任意网页 → 右下角 **AI** 按钮 → ⚙ 模型设置 → 识别题目。

## 模型配置说明

| 配置 | 说明 | 示例 |
|---|---|---|
| API 地址 | OpenAI 兼容接口，**不含** `/chat/completions` | `https://api.deepseek.com/v1` |
| API Key | 你的密钥 | `sk-...` |
| 模型名称 | 模型 ID | `deepseek-chat` |
| 温度 | 0~2，越低越稳定 | `0.3` |
| 超时(ms) | 单次请求超时 | `120000` |
| 自定义请求头 | 每行一个 `Header: value` | `X-Org: xxx` |
| 系统提示词 | 控制输出格式 | 见默认值 |
| 流式 | 逐字显示答案 | 开 |
| 自动填入 | 得到答案后自动勾选/填写 | 开 |
| 批量 | 一次请求全部题目 | 关 |

> 提示词默认要求：选择题给字母（多选用如 `ABD`）、判断题给“正确/错误”、填空/简答直接给答案文本。

## 识别与答题

- **自动识别**：优先用「自定义选择器」→ 常见平台规则（问卷星 `.div_question` 等）→ 启发式扫描。
- **🎯 点选题目**：自动识别不到时，点「点选题目」，再在页面上逐题点击题目区域，可连点，最后点「识别题目」。
- **iframe**：扫描范围包含同源 iframe。
- **手动调整**：每题下方显示干净选项 chips，点选后可「填入答案」；填错可再点。

## 常见问题

| 现象 | 处理 |
|---|---|
| 点「识别题目」没反应 | 现在任何错误都会在状态框显示。先确认已填 API 地址 + Key；再点「诊断」看命中情况 |
| 识别不到题目 | 点「🎯 点选题目」手动逐题点；或填「自定义选择器」；或确认题目不在跨域 iframe 里 |
| 请求失败/跨域 | 用户脚本用 `GM_xmlhttpRequest`、扩展用后台 `fetch`，都已绕开跨域；检查 API 地址/Key 是否正确 |
| 答案不对/类型识别错 | 手动点选项 chips 后点「填入答案」；或在「自定义选择器」里用更精确的选择器定位 |
| 选项乱/重复 | 已改为文本解析（按 `A. B. C.` 拆分）。若平台用 `①`/`(1)`/纯文字，发我页面片段补解析规则 |
